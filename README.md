## Hello

I teach mathematics at a high school.
I write class handouts in LaTeX, and automate repetitive tasks in lesson preparation and school administration with Node.js and similar tools.
Within mathematics, differential geometry is my favorite field.

### What I work on

- **A LaTeX environment for teaching materials**: a local LaTeX editor with compile-on-save, PDF preview, and SyncTeX
- **Claude Code mods**: small extensions that make working with AI smoother, such as a pixel-art pet, a band that keeps decisions in view, and a nudge toward choice-based questions

### Featured repositories

| Repository | Description |
|---|---|
| [claude-dotpet](https://github.com/i-noma-ru/claude-dotpet) | My first published project. A pixel-art pet shown in the Claude Code screen, with a browser editor to redraw it |
| [latex-editor](https://github.com/i-noma-ru/latex-editor) | A local web editor for LaTeX: compile-on-save, PDF preview, and bidirectional SyncTeX navigation |
| [claude-decision-tracker](https://github.com/i-noma-ru/claude-decision-tracker) | A Claude Code mod that keeps decisions mentioned in replies in a band above the prompt until the decision log is written |
| [claude-ask-choice](https://github.com/i-noma-ru/claude-ask-choice) | A Claude Code mod: when Claude ends a reply with a choice-based question in plain text, it prompts Claude to ask it again with selectable options |
| [claude-drop-thumb](https://github.com/i-noma-ru/claude-drop-thumb) | A Claude Code mod that shows a thumbnail and file name for images dropped onto the prompt |
