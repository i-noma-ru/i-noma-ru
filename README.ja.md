## こんにちは

高校で数学を教えています。
授業で使うプリントは LaTeX で作り、教材づくりや校務で繰り返す作業は Node.js などで自動化しています。
数学の中では微分幾何学が好きです。

### 主な取り組み

- **LaTeX 教材づくりの環境**：ローカルで動く LaTeX エディタ（保存時コンパイル・PDF プレビュー・SyncTeX）
- **Claude Code の拡張（mod）**：ドット絵のペット、決定事項の表示、選択式の質問への誘導など、AI と作業するときの使い勝手を整える小さな拡張

### 代表的なリポジトリ

| リポジトリ | 内容 |
|---|---|
| [claude-dotpet](https://github.com/i-noma-ru/claude-dotpet) | 最初に公開した作品。Claude Code の画面に表示されるドット絵のペットで、ブラウザのエディタで描き直せる |
| [latex-editor](https://github.com/i-noma-ru/latex-editor) | ローカルで動く LaTeX エディタ。保存するとコンパイルし、PDF プレビューとソースの間を SyncTeX で双方向に行き来できる |
| [claude-decision-tracker](https://github.com/i-noma-ru/claude-decision-tracker) | 返答の中で決まった事項を、記録されるまでプロンプトの上に表示し続ける Claude Code mod |
| [claude-ask-choice](https://github.com/i-noma-ru/claude-ask-choice) | Claude の返答が選択式の質問を文章のまま書いて終わったとき、選択肢つきの形で聞き直させる Claude Code mod |
| [claude-drop-thumb](https://github.com/i-noma-ru/claude-drop-thumb) | プロンプトにドロップした画像のサムネイルとファイル名を表示する Claude Code mod |
